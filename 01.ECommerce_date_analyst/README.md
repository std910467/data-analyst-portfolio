# 01. E-Commerce Data Analysis (Olist)
## 📌 專案說明
使用 Olist 電商資料，透過 SQL 建立分析用資料表，並用 Python 做簡單視覺化，觀察營收、顧客與商品結構。

---

## 📊 分析內容
- 營收成長（Revenue / MoM）
- 顧客留存（Cohort：M1 / M2 / M3）
- 顧客價值（RFM）
- 商品分析（Top 商品 + 集中度）
---
## 🗂 資料處理
- 使用 `customer_unique_id` 當作顧客
- 分析區間：2017-01 ~ 2018-08  
  （2016 資料偏測試，2018-09 不完整）
- 商品分類缺失補為 `Uncategorized`
---
## 🧱 資料表設計
### 中間表
- int_order_summary（訂單層）
- int_order_product（商品層，一筆訂單可能多商品）
### 分析表（Mart）
###
### RFM表格月份統計錯誤要改，product表要改應該用長表所有產品都上，但保留排名。
###
- mart_monthly_revenue（營收 + 成長率）
- mart_monthly_retention（新客 + 留存）
- mart_month_customer_segment（RFM）
- mart_month_product（Top 商品 + 集中度）
---
## 🔍 一些觀察
- 約 97% 顧客只買一次 → 留存非常低（這點一開始有點意外，但後來覺得合理）
- 營收成長主要來自新客，而不是回購
- 高價客每月都有，但沒有累積成長成 VIP
- 有些月份商品集中度很高，風險比較集中
---
## 📈 Python 分析
### 營收
- 整體是往上走
- 2017-11（大促銷）營收明顯拉高
- 隔月會掉下來，但長期還是成長
- 2018-03 之後成長有點停滯，甚至出現負成長
### 留存
- 留存幾乎都 <1%，用 heatmap 看不太出來，改用柱狀圖
- 2017-11 大促銷帶來很多新客，但隔月留存沒有變好，甚至變低
---
## 🧠 自己的理解
一開始以為大促銷會讓留存變好，但實際上沒有，可能原因：
1. 有些人會等促銷才買（延後需求）
2. 提前買的人通常是「急用」，買完就走
3. 大促吸引很多只看價格的人（羊毛客），不會留下來
👉 感覺這個平台比較像是「流量型」，不是靠回購在成長
