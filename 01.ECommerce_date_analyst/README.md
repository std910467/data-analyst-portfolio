# 01. E-Commerce Data Analysis (Olist)

## 專案說明
使用巴西 Olist 電商公開資料，用 SQL 整理分析用資料表，再用 Python 做視覺化，最後用 Power BI 做成儀表板。

主要想了解：
- 營收成長比較像靠新客，還是靠既有顧客
- 顧客有沒有回購（留存）
- 營收是否集中在少數高消費顧客
- 商品銷售是少數爆品帶動，還是多個品類一起支撐

這是我轉職資料分析的第一個完整練習專案，重點是把流程跑通：  
資料處理 → 建表 → 觀察 → 視覺化。

資料匯入以 DBeaver 為主；`olist_order_reviews_dataset` 因評論內容有換行，匯入精靈不易處理，改以 Python 匯入。

## SQL 資料表設計

### 中間表
- `int_order_summary`：訂單層彙總
- `int_order_product`：商品層明細（一筆訂單可能有多個商品）

### 分析表（Mart）
- `mart_monthly_revenue`：月營收與成長率
- `mart_monthly_retention`：新客與留存
- `mart_monthly_customer_segment`：顧客價值分群
- `mart_monthly_product`：商品表現

## Python 圖表分析

用 Python 做了 4 張圖，分別看營收、留存、顧客價值與商品表現。

### 1. 月營收與成長
- 整體營收呈上升趨勢
- 2017-11 有明顯高峰（推測與大促有關），隔月回落，但長期仍往上
- 2018-03 之後成長放緩，部分月份出現負成長

### 2. 顧客留存
- 每月留存率大多低於 1%；heatmap 不易看出差異，改用柱狀圖較清楚
- 約 97% 顧客只購買一次，回購很少
- 2017-11 大促帶來較多新客，但隔月留存沒有提升，甚至更低

因此判斷：這個平台比較像靠新客與流量成長，留存分析的參考價值有限。

### 3. 顧客價值貢獻
原本打算做傳統 RFM，但多數顧客只買一次：
- Frequency 幾乎都是 1，不易分群
- Recency 在圖上也看不出明顯差異

後來改成依消費金額分群，比較高消費客群與一般客群的營收貢獻。

目前觀察：
- 約前 20% 高消費顧客，貢獻約一半營收
- 早期高消費客群佔比較高；隨用戶增加，結構逐漸接近一半一半

### 4. 商品銷售熱力圖
用來觀察各品類在不同月份的銷售與排名：
- `health_beauty` 表現較穩，2018 年後更常排在前面
- `bed_bath_table`、`sports_leisure`、`watches_gifts` 長期較穩定
- 電腦相關類別在部分月份衝高，但延續性較弱

整體來看，營收比較像由多個較穩定的品類一起支撐，而不是長期只靠單一爆品。

## 結論

依目前分析，Olist 大致有這些特性：

1. 營收成長主要來自新客，而不是既有顧客回購  
2. 顧客留存偏低，多數人只買一次  
3. 商品端較像多個穩定品類共同支撐，而不是單一爆品長期主導  

整體來說，這個平台的成長比較偏向流量／新客導入，而不是靠顧客長期經營。
