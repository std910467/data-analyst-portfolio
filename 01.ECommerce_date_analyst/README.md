# 01. E-Commerce Data Analysis (Olist)

## 專案說明
使用巴西 Olist 電商公開資料，用 SQL 整理分析用資料表，再用 Python 做視覺化，最後用 BI 做成可互動的儀表板。  

主要想了解這間電商平台的：
- 營收如何變化
- 顧客是否會回購
- 營收主要靠哪一類顧客與商品在支撐

這是我轉職資料分析的第一個完整練習專案，重點放在把分析流程跑通：資料處理 → 建表 → 觀察 → 視覺化。

---

## 分析內容
- 月營收與 MoM 成長
- 顧客留存（Cohort：M1 / M2 / M3）
- 顧客價值分群（由 RFM 調整而來）
- 商品分析（Top 商品、集中度）

---

## 資料處理
- 顧客識別：使用 `customer_unique_id`
- 分析區間：2017-01 ~ 2018-08  
  （2016 資料偏少、較像測試；2018-09 之後不完整，所以排除）
- 商品分類缺失值補成 `Uncategorized`

---

## SQL 資料表設計

### 中間表
- `int_order_summary`：訂單層彙總
- `int_order_product`：商品層明細（一筆訂單可能有多個商品）

### 分析表（Mart）
- `mart_monthly_revenue`：月營收與成長率
- `mart_monthly_retention`：新客與留存
- `mart_monthly_customer_segment`：顧客價值分群
- `mart_monthly_product`：商品表現

## Python 圖表分析

用 Python 做了 4 張圖，分別看營收、留存、顧客價值，以及商品表現。

### 1. 月營收與成長
- 整體營收呈上升趨勢
- 2017-11 有明顯高峰（推測與大促有關），隔月回落，但長期仍往上
- 2018-03 之後成長放緩，部分月份出現負成長

### 2. 顧客留存
- 每月留存率大多低於 1%；heatmap 差異不明顯，改用柱狀圖較清楚
- 約 97% 顧客只購買一次，回購很少
- 2017-11 大促帶來大量新客，但隔月留存沒有提升，甚至更低

因此判斷：這個平台比較像靠新客與流量成長，留存分析的參考價值有限。

### 3. 顧客價值貢獻
原本打算做傳統 RFM，但多數顧客只買一次：
- Frequency 幾乎都是 1，難以分群
- Recency 在圖上也看不出明顯差異

後來改成依消費金額分群，比較高消費客群與一般客群的營收貢獻。

目前觀察：
- 約前 20% 高消費顧客，貢獻約一半營收
- 早期高消費客群佔比較高；隨用戶增加，結構逐漸接近一半一半

### 4. 商品銷售熱力圖
用來看各品類在不同月份的銷售與排名：

- `health_beauty` 表現較穩，2018 年後更常排在前面
- `bed_bath_table`、`sports_leisure`、`watches_gifts` 長期穩定
- 電腦相關類別在部分月份衝高，但延續性較弱
