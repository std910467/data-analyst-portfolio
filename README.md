## 📌 專案列表

### 01. E-Commerce Data Analysis (Olist)

使用 Olist 電商資料進行分析，從資料清理、建模到初步視覺化。

主要內容：

* SQL 建立分析資料表（Revenue / Retention / RFM）
* Python 讀取資料並畫出營收與成長趨勢
* 嘗試解讀顧客行為與平台營運模式

👉 重點觀察：

* 營收成長主要來自新客，而非回購
* 留存率極低（多為一次性消費）
* 大促銷帶來流量，但不一定帶來留客
